# Unity-Texture2dGenerator

Adds an entry to the Tools menu that opens a window within the Editor to create a Texture2DArray from textures added to the list.

To open: 
    Tools -> Texture2DArray Generator

Notes: 
    Unity doesn't allow textures too be compressed when generating the texture array
    Textures ned to be of the same size
