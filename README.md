# Unity Texture2D Array Generator

<h4>About</h4>
Simple tool that adds an entry to the Tools menu that opens a window within the Editor to create a Texture2DArray from textures added to the list.

<h4>Open: </h4>
    Tools -> Texture2DArray Generator

<h4>Notes: </h4>
    Unity doesn't allow textures too be compressed when generating the texture array
    <br/>
    Textures ned to be of the same size
